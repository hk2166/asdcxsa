Decision logic

No look-ahead: only what the trader could have seen

Decision for day D = gate closure on D−1, UK time (09:20 EPEX, 09:50 N2EX)
Each hour of D: newest run published at or before the gate. Nothing later.
Runs pre-sorted by publish time → binary search
UTC inside, Europe/London at the edges → 23 / 25-hour clock-change days
Hourly forecast ↔ half-hour actual starting at the same time (other alignments within ~1%)

Analysis

Honest metrics, and a range built only from the past

error = forecast − actual (+ = over-forecast)
MAEmean |error|
RMSE√ mean error²
Biasmean error
WAPEΣ|error| ÷ Σ actual

WAPE stays stable in calm hours, where plain % error explodes.
